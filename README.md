## What is SmartBudget Manager?

SmartBudget Manager is an Excel workbook that helps users track personal income and expenses and review a monthly financial summary.

## Main worksheets

- **Transactions:** enter each income or expense in a new row, filling in the fields available in the workbook.
- **Categories:** view predefined expense categories, such as Food, Transport, Rent, Health, and Education.
- **Dashboard:** review the monthly summary and any charts provided by the workbook.

## Requirements

- Microsoft Excel or a compatible spreadsheet application.
- Basic ability to open, edit, and save a spreadsheet.

## Getting started

- Open the SmartBudget Manager workbook in Excel.
- Go to the Transactions worksheet.
- Enter a transaction in an empty row, using the available columns.
- Choose the appropriate type and category, and enter the amount.
- Check the Dashboard to review the updated summary.
- Save the workbook after making changes.

## Important note

Use the workbook's actual column labels and formulas. Features such as budget alerts or charts depend on how the supplied workbook is configured.
